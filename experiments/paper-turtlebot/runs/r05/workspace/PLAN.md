Identification plan (recorded before fitting)

Use only data/train.csv. Compare (1) physical differential-drive/unicycle kinematics, both forward-Euler and constant-twist integration; (2) an affine body-frame velocity map permitting lateral translation and angular bias; (3) parsimonious nonlinear command maps, including cubic response and forward-speed-dependent turning; (4) a sparse regression extension using low-order command and periodic-heading features if residuals justify it. No absolute-position dependence is planned because the planar system should be translation invariant. Assess short (about 5 s) uncorrected rollouts, leave-one-trajectory-out validation, and long training rollouts. Inspect heading increments, body-frame displacement residuals, and command dependence. Pose measurement error motivates multi-step output-error fitting rather than relying only on noisy one-step differences. Prefer identifiable low-dimensional models; retain structurally distinct defensible families, not many numerical variants of one form. Document actual methods, initial values, exclusions, and limitations in each candidate.
