Pre-fit plan

Compare (1) unicycle/differential-drive kinematics with Euler, midpoint and constant-command circular-arc integration; (2) calibrated kinematics with command gains, additive command biases and heading offset; (3) nonlinear command-response models using polynomial or saturation maps and turn-dependent forward motion; and (4) sparse regression over a physically motivated trigonometric velocity library if residuals justify it. State translation invariance will be preserved unless clear evidence contradicts it. Fit using multi-step output-error criteria because logged states have measurement error; examine one-step residuals and use leave-one-trajectory-out and 25-step window simulation validation. Inspect ranges, command holding/alignment, heading wrapping and outliers first. Pool will contain defensible structural alternatives, not merely coefficient variants. No test data will be accessed.
