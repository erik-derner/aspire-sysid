# Provenance of the task `task-jdhj`

For the user only; never provisioned into a working directory (tasks/README.md, Section 5).

Blind variant of the described task `friction-driven`, generated by `tasks/make_blind.py`. The data values are identical to those of the described task: every data and test file is the described file with only its header row renamed; row order and trajectory boundaries are unchanged. Origin and construction of the data: `tasks/friction-driven/provenance.md`. The complete mapping and the list of kept, replaced and omitted fields: `tasks/BLIND_MAPPING.md`.
